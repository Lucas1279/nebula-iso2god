Nebula ISO2GOD website update package

IMPORTANT: Publish this update to Lucas1279/nebula-iso2god (the ISO2GOD repository), not Lucas1279/Nebula-convert. These are separate websites.

To publish from GitHub's website (no GitHub Desktop required): open the Lucas1279/nebula-iso2god repository, make sure you are on the branch used by GitHub Pages, and upload/replace these files at the repository root:
- index.html
- ftp_helper.py
- README_FTP.md
- the complete vendor/ directory (keep its subfolders and files)
- nebula-iso2god-timeout-fix.zip
- Nebula-ISO2GOD-One-File.zip
- Nebula-ISO2GOD-One-File-Fixed.zip

Commit the replacement files to the published branch, then wait for GitHub Pages to redeploy at https://lucas1279.github.io/nebula-iso2god/.

For raw XBLA/XBLIG uploads, use the extracted-folder workflow: unzip the game archive on your Mac, then select/drop the extracted 8-character Title ID folder (for example `584111FF`) or its parent game folder. The page finds files under `000D0000` and uploads them unchanged. Do not select the outer archive, only the `000D0000` folder, or an individual file. The ISO conversion workflow's existing local `.7z` image import remains supported.

The page also keeps the separate blue Xbox-transfer bar beneath the overall conversion bar, with the current Data####/filename, bytes, and transfer speed. In the raw XBLA/XBLIG uploader, the overall job bar aggregates progress across all selected content files, while the blue bar and filename/bytes/speed line track the current file. It includes the rotating UFO disc and staggered theme-matched lights. Data required for an FTP retry is retained.

The ISO .7z image importer runs locally in a recent Safari, Chrome, or Edge browser on HTTPS or through the updated local helper at http://127.0.0.1:8765/ (not file://). Only supported image entries are extracted. Browser site storage must have enough free space for the extracted images. Password-protected or damaged archives are not supported.

The app does not delete your downloaded .command/.zip files or files already written to the Xbox. FTP is unencrypted; use it only on a trusted home LAN.
