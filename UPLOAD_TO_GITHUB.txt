The Mac download includes an executable .command file. The fixed filename is used by the website so browsers are less likely to serve a cached old archive. Both the local helper and hosted site now expose the worker and WASM assets from vendor/ with the correct JavaScript/WebAssembly MIME types, which allows the .7z module worker to load. Upload the refreshed index, helper, vendor tree, and ZIPs together.

The ISO workflow can import .7z archives locally in recent Safari, Chrome, or Edge when opened over HTTPS or the updated local helper at http://127.0.0.1:8765/ (not file://). Supported disc images are extracted to browser storage; other entries are skipped and the original archive is unchanged.

FTP transfer pauses on a failed package-file transfer and offers “Retry file & continue.” A retry resends only the current file from byte zero using FTP STOR (not byte-offset resume), overwrites any partial console copy, and continues the current ISO/job; completed files stay in place. Keep the page and helper open while paused.

Includes separate ISO and XBLA/XBLIG workflows, saved IP/username options (password never saved), sequential-only FTP uploads, and completion animations for successful conversion and raw upload. Animations respect the system reduced-motion setting.
