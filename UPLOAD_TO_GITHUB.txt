Website FTP upload update

This folder contains the updated converter page and download assets. Upload/replace these files in the root of the GitHub repository used by GitHub Pages, commit the changes to the published branch, then wait for Pages to redeploy:
- index.html
- ftp_helper.py
- README_FTP.md
- nebula-iso2god-timeout-fix.zip
- Nebula-ISO2GOD-One-File.zip

The page now offers both timeout-fixed downloads and a separate direct XBLA/XBLIG content-file FTP uploader. That uploader preserves filenames and bytes and writes to Content/0000000000000000/<TitleID>/000D0000/.
